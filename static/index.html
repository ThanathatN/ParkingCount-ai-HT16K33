รถเข้า / ออก วันนี้ รายชั่วโมง

ติดตั้งป้าย LED ใหม่ (ESP32 + HT16K33)
  1. ต่อสาย: (ESP32)VIN→(LED)VCC, (ESP32)GND→(LED)GND, (ESP32)D21→(LED)SDA, (ESP32)D22→(LED)SCL
  2. Arduino IDE ติดตั้งไลบรารี WebSockets (Markus Sattler), ArduinoJson 7.x, Adafruit LED Backpack
  3. กรอก WiFi ด้านขวาแล้วกด “ดาวน์โหลดเฟิร์มแวร์” ระบบใส่ IP เซิร์ฟเวอร์และรหัสอุปกรณ์ให้อัตโนมัติ
  4. อัปโหลดลงบอร์ด (Board: ESP32 Dev Module) เฟิร์มแวร์เดียวใช้ได้ทุกป้าย
  5. เปิดเครื่อง ป้ายจะขึ้นในตารางนี้เอง (แถวสีเหลือง) กด “ตั้งค่า” เพื่อตั้งชื่อและเลือกชั้น
จอแสดง WIFI = กำลังต่อ WiFi · CONN = กำลังต่อเซิร์ฟเวอร์ · มีจุดหลักขวาสุด = หลุดชั่วคราว · ---- = ยังไม่กำหนดชั้น หรือหลุดเกิน 60 วินาที
รหัสอุปกรณ์ช่วยกันไม่ให้อุปกรณ์อื่นในเครือข่ายเชื่อมเข้ามาได้ ถ้าเปลี่ยนรหัส ต้องแฟลชเฟิร์มแวร์ใหม่ทุกป้าย

ตั้งค่าการแจ้งเตือน

“รวมเหตุการณ์” ช่วยไม่ให้ข้อความถี่เกินไปช่วงรถเยอะ เช่น 3 วินาที = รถที่ผ่านติดกันภายใน 3 วินาที รวมเป็นข้อความเดียว (Telegram จำกัด ~20 ข้อความ/นาที ต่อกลุ่ม)
วิธีสร้างบอทและหา Chat ID
  1. ใน Telegram คุยกับ @BotFather พิมพ์ /newbot ตั้งชื่อ แล้วคัดลอก Token มาใส่ด้านบน กดบันทึก
  2. เพิ่มบอทเข้ากลุ่มที่ต้องการ (หรือทักบอทโดยตรง) แล้วพิมพ์ /start ในกลุ่ม
  3. กด “ค้นหา Chat ID” แล้วเลือกห้อง หรือคัดลอกเลขที่บอทตอบกลับมา
  4. โหมดข้อความสถานะเดียว: ให้บอทเป็นแอดมินกลุ่ม เพื่อปักหมุดข้อความได้
  5. ในห้องที่ตั้งไว้ พิมพ์ /status เพื่อดูสถานะทุกชั้นได้ทุกเมื่อ
